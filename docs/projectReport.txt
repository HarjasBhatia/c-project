Project Report: Matchstick Game
Date: 24 November 2025
Author: HarjasBhatian and Harsh Chaudhary

1. Project Overview
This project implements an enhanced Matchstick Game in C programming language.
The game features a player versus computer format where participants take turns removing matchsticks from a pool. The player who is forced to take the final matchstick loses the game.

2. Game Rules
- Total matchsticks: 101
- Players can pick 1 to 9 matchsticks per turn
- The player who takes the last matchstick loses
- Players alternate turns between human and computer
- Game includes multiple rounds with statistics tracking

3. Technical Specifications
- Programming Language: C
- Compiler: GCC compatible
- Platform: Cross-platform (Windows/Linux/macOS)
- Files: 3 source files (header, main, game logic)

4. Project Structure
matchstick_game.h - Header file containing constants and function declarations
main.c - Primary game loop and user interface
game_logic.c - Core game mechanics and computer AI

5. Key Features
- Intelligent computer opponent with strategic gameplay
- Input validation and error handling
- Game statistics tracking (wins/losses/win rate)
- Multiple game sessions support
- Visual matchstick display
- Randomized starting player

6. Computer AI Strategy
The computer uses mathematical strategy based on modulo operations to create optimal moves.
It occasionally makes suboptimal decisions (15% chance) to provide winning opportunities for human players, making the game more engaging and balanced.

7. Build Instructions
Compilation: gcc -o matchstick_game main.c game_logic.c -I.
Execution: ./matchstick_game
